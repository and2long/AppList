# AppList

AppList helps you view information about installed apps on your device.

## Features

- View user apps
- View system apps
- Display app icon, app name, package name, version name, and version code
- View app details:
  - minSdkVersion
  - targetSdkVersion
  - Signature MD5
  - Signature SHA1
  - Signature SHA256
- Open an app
- Open the Android system app detail page
- Share formatted app details
- Supports English and Simplified Chinese
